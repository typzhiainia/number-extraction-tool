# 号码提取工具 (Number Extraction Tool) v4.6

## 简介

号码提取工具是一个**纯浏览器端**的在线工具，用于从混合文本中快速提取中国内地11位手机号码（13-19号段），自动过滤座机号码，并按公司名称分组展示结果。

## v4.1 → v4.6 新增功能

### 1. 导出文件名自定义

提取完成后，可在结果上方直接编辑导出文件名，按需命名。文件导入时自动以导入文件名作为默认导出名，手动粘贴时恢复默认值「手机号码」，导出文件名格式为 `自定义名称_YYYYMMDD.ext`。

### 2. CSV 智能列解析

- **RFC 4180 兼容**：正确处理含逗号的引号字段和转义引号，不再因字段内含分隔符导致解析错位。
- **结构化列识别**：自动检测 CSV 表头中的「名称」列和「电话」列，提取时只取相关列，**跳过地址、坐标、城市等噪声列**，大幅减少误提取。
- **多电话列合并**：支持识别表头中的多个电话列（如联系电话、联系手机、备用电话），自动合并输出。

### 3. 跨公司去重

同一号码出现在多家公司时，仅归入首次出现的公司，后续公司不再重复计数，避免统计数字虚高。

### 4. 统计面板增强

- **去重手机号码**卡片升级为高亮样式（主题色背景），作为最核心指标突出展示。
- 新增 **重复次数提示**：显示原始数据中号码出现的总次数（含重复），帮助用户评估数据质量和重复率。
- 新增 **忽略列统计**：统计因识别为坐标/地址/城市而被忽略的数值列数。

## 核心功能

- **智能提取**：支持公司名+号码混合文本、纯号码行、+86前缀号码、粘连号码等多种格式，不丢号。
- **自动过滤座机**：识别并剔除7-12位非手机号码（如座机、短号），并在统计面板中报告过滤数量。
- **多文件导入**：支持拖入 TXT / CSV / XLSX 文件（含多Sheet），CSV 编码自适应（UTF-8 / GBK），文件大小上限 20MB。
- **公司名分组**：自动识别公司名，将同一公司的多个号码合并展示；纯号码数据归类为「未关联公司」。
- **去重统计**：展示公司数量、手机号码总数（含重复次数）、去重号码数、过滤座机数、无号码行数、忽略列数。
- **搜索与分页**：支持按公司名搜索，支持 20/50/100/200 条分页浏览。
- **多种导出格式**：
  - TXT 导出（去重手机号码列表）
  - XLSX 导出（公司名 + 多列号码，纯号码场景自动切换单列）
  - SHA256 加密 TXT 导出（号码哈希脱敏）
  - SHA256 加密 XLSX 导出（号码哈希脱敏，保留公司名）
- **一键操作**：粘贴剪贴板、复制全部号码、按公司复制号码。

## 风险提示

> **安全声明：** 本工具所有数据处理均在您的浏览器本地完成，**不会上传任何数据到服务器**。页面加载后可断开网络正常使用。号码数据仅存在于当前页面，关闭或刷新即清除，请及时导出保存。

## 适用场景

- 从客服记录、销售报表中批量提取客户手机号
- 数据清洗时从混杂文本中分离手机号码
- 合规场景下导出 SHA256 加密号码用于数据共享

## 技术实现

纯前端单文件实现，无后端依赖。使用 Material Design 3 风格 UI，内置 SheetJS 库解析 Excel 文件，利用 Web Crypto API 实现 SHA256 哈希。

## 使用方式

直接用浏览器打开 `number-extraction-tool.html` 即可使用，无需安装任何依赖。
